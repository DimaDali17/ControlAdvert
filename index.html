Детализация: день → артикул → размер

Дата Артикул Размер Заказы Расход рекл. Показы Клики CTR CR Прибыль до рекл. Прибыль после рекл.
Показы, клики, CTR и CR — на уровне артикул/день (реклама не делится по размерам), поэтому повторяются в строках размеров. Расход рекламы распределяется по размерам равномерно; прибыль = заказы × выкупаемость × «прибыль до рекламы» из таблицы; «после рекламы» = минус распределённый расход. Для размеров с особой прибылью (строка артикул;размер в таблице) берётся именно её значение, а не базовое по артикулу. Значок «∅» — размер исключён из распределения рекламы (расход 0).

Бесплатный прокси за 3 минуты

Браузер не может обращаться к WB API напрямую (нет CORS-заголовков). Cloudflare Worker решает это и бесплатен до 100 000 запросов в день.

  1. Откройте dash.cloudflare.com → Workers & Pages → Create → Worker.
  2. Удалите шаблон, вставьте код ниже, нажмите Deploy.
  3. Скопируйте адрес вида https://wb-proxy.…workers.dev в поле «URL прокси».
